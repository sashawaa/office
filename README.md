# Виртуальный прототип сети офиса с IoT-управлением охлаждением

## Цель проекта
Разработать и продемонстрировать работающий виртуальный прототип сетевой инфраструктуры нового офиса организации. В серверной автоматически включается охлаждение при повышении температуры, а сотрудник может со своего рабочего места следить за состоянием оборудования и при необходимости управлять вентилятором вручную.

# Умное помещение — система мониторинга и управления

## Назначение
Автоматический сбор показаний температуры и влажности, 
управление вентилятором по порогу, хранение в SQLite, 
мониторинг в Prometheus/Grafana, почтовые оповещения.

## Схема обмена данными
IOT-01 → Node-RED → CTRL-01 (/api/readings) → SQLite (DB)
CTRL-01 → Prometheus (метрики) ← Grafana (дашборд + алерты)
Grafana → SMTP Gmail → почта оператора

## Запуск
1. docker-compose up -d (на CTRL-01)
2. systemctl start prometheus grafana-server (на MON-01)
3. Открыть Node-RED → Deploy flows.json
