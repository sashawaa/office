### Возможные проблемы и их решение
Отсутствие интернета на клиентах: Выключен IP forwarding на шлюзе или отсутствует правило NAT. Решение: включить ip_forward и добавить правило masquerade.
Ошибка wrong-type при создании VLAN: Попытка создать VLAN через nmtui. Решение: использовать nmcli из командной строки.
Windows Server не пингуется: Брандмауэр Windows блокирует ICMP. Решение: отключить брандмауэр или добавить правило для ICMPv4.
Неверная маска подсети: Использование маски /24 вместо /26. Решение: строго указывать маску 255.255.255.192.
